# Hocker AGI Technologies — Official Public Site

Sitio oficial comercial del ecosistema Hocker AGI Technologies, construido en Next.js para Vercel.

## Incluye
- Home comercial
- Ecosistema de apps
- Explicación clara de NOVA y las AGIs
- Portafolio / CV de Armando Chávez
- Página de soluciones
- Página de contacto
- Páginas por app
- SEO básico: metadata, robots, sitemap, JSON-LD

## Instalación
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
npm run start
```

## Personalización
- Edita `src/lib/site-data.ts` para cambiar apps, servicios, AGIs y portfolio.
- Cambia las imágenes dentro de `public/`.
- Ajusta el contenido de la home en `src/app/page.tsx`.

## Logos
- El sitio usa los logos existentes en `public/apps/` y `public/brand/`.
- Si quieres branding completo por app, conviene subir manualmente iconos dedicados para:
  - `public/apps/chido-casino/icon.png`
  - `public/apps/hocker-up/icon.png`
